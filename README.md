## 🔄 Data Analysis Workflow

**1. Collect Data**

Import data from Excel, CSV files, databases, or other available sources.

**2. Clean Data**

Identify and handle:

* Missing values
* Duplicate records
* Incorrect data types
* Formatting problems
* Inconsistent categories

**3. Analyze Data**

Use **Excel and SQL** to answer business questions, calculate KPIs, identify trends, and explore relationships within the data.

**4. Visualize Data**

Use **Power BI** to create interactive dashboards containing:

* KPI cards
* Charts
* Tables
* Filters
* Slicers
* Trend analysis

**5. Communicate Insights**

Summarize the most important findings and provide clear, data-driven recommendations.
